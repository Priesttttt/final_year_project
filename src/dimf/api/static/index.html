Class A — CRDT cluster

Zero-coordination writes; gossip converges counters and LWW registers.

Class B — Raft cluster

Leader-based replicated log with terms, commit indexes and failover.

Class C — PBFT cluster

n = 3f + 1 normal-case consensus; one Byzantine backup is tolerated.

Known limits: PBFT has no view change, so a Byzantine primary is fatal; Raft state is in memory; “crash” is a simulated flag, not a process exit.
